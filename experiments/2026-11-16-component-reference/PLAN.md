# 電池等式と線形上下限の独立高精度参照

2026-11-16、基準7aaa8e6。利用率の許容はユーザー指示の95%程度。
前の大小2最終点の最後のTR方向、幅1e-8/1e-10/1e-12・正負の12点と基準2点だけを使う。
新しい最適化は起動しない。選択は計算前にtargets.jsonへ固定する。

標準Decimalの80桁/100桁で、電池CC-CV写像・等式と線形な5種類の上下限制約を独立に評価する。
入力point・物理定数・尺度・行尺度・AL乗数/rhoは元の倍精度値をDecimalへ正確に変換する。
range/sigmaなどnativeで先に計算された定数もその倍精度値を保持し、同じパラメータで算術精度を変える。
負の充電時間も既存の符号付きODEの分岐を踏襲し、指数上限60を保持。

単体検査で充電の恒等性/CC直線/符号付き逆写像、PHR差分と線形上下限の解析例を確認してから実データを評価。
全14点でnative制約と一致する精度（絶対2e-14以内）を確認し、80/100桁の部分AL値差が1e-60以内で一致することを検査。
nativeの電池/上下限の寄与を高精度参照へ置き換えた部分補正値も保存するが、全モデルの高精度評価や勾配/収束改善とは扱わない。
他の制約と勾配は今回の参照の対象外。任意の係数調整や対象の追加で結果を選び直さない。
